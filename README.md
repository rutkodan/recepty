# Recepty

Osobní sbírka receptů v Markdownu.

## Struktura

```
recepty/
├── recepty/           # Jednotlivé recepty (.md)
│   ├── hlavni-jidla/
│   ├── polevky/
│   ├── prilohy/
│   ├── dezerty/
│   ├── peceni/
│   ├── napoje/
│   └── ostatni/
├── sablona.md         # Šablona pro nový recept
└── README.md
```

## Jak přidat recept

Pošli recept Claudovi (libovolný formát — text, foto, odkaz) a on ho zapíše do správné složky podle šablony v [`sablona.md`](sablona.md).

Soubory pojmenovávej bez diakritiky a s pomlčkami: `svickova-na-smetane.md`.
